# Квантовая природа света — открытый урок физики

Интерактивная презентация для сенсорной доски: один файл `index.html`, работает без интернета.

**Открыть:** https://sukrievmusa-hash.github.io/--/

- 19 слайдов: кризис классической физики, гипотеза Планка, фотоэффект, уравнение Эйнштейна, фотон, дуализм, применение
- Виртуальная лаборатория фотоэффекта (длина волны, яркость, металл, график Eₖ(ν))
- Калькулятор фотона
- 4 игры для команд: викторина, «Верно / Неверно», «Волна или фотон?», «Будет ли фотоэффект?»
- Маркер ✏️ для рисования пальцем поверх любого слайда

Управление: ▶ / ◀ внизу, свайп, стрелки клавиатуры. ⛶ — на весь экран, ☰ — список слайдов.
